# AIR-INK V3 — Carbon Recovery Digital Twin

High-visual static web simulator for an engineering final-year project.

## Deploy
Upload `index.html`, `style.css`, `script.js`, and `README.md` to a public GitHub repository. GitHub Pages can host the static site for free.

## Model
PM input = Q × C_PM × t
Captured = PM input × capture efficiency
Usable carbon = captured × purification recovery
Estimated ink = usable carbon ÷ ink solids fraction

## Important scientific boundary
This is an educational/illustrative model. It treats particulate matter as a carbon-rich fraction and does not validate a real exhaust-capture, purification, or ink-formulation process. Replace illustrative parameters with measured experimental data for research claims.
